#### **This repositories verse about the two projects done during "Herramientas Informaticas para la Bioinformatica" Lecture, encompassed in the Bioinformatics and Biostatistics Master taught by the University of Barcelona and the Open University of Cantalunya**
##### The first two folders focus on using the Linux console for processing biological datasets
##### The third covers the use of Bioconda libraries, Docker, and Nextflow.
##### At lat, the fourth deals with the use of SQL and NoSQL databases, such as MongoDB.
